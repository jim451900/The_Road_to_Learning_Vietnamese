# templates

模板只定义“记什么”，不定义“学什么”。学习内容来自 `../01_发音系统/` 与 `../02_句子积木/`。

| 模板 | 什么时候用 | 填完去哪里 |
|---|---|---|
| [01_发音打卡模板.md](01_发音打卡模板.md) | 每天发音训练后 | `../00_导航/03_进度看板.md`、`../03_错题与复盘/个人错音清单.md` |
| [02_句子积木练习模板.md](02_句子积木练习模板.md) | 每天句子积木练习后 | 同上；最顺口 3 句进入个人常用句库 |
| [03_每周复盘模板.md](03_每周复盘模板.md) | 每周结束、Day15 | `../03_错题与复盘/每周复盘.md`、`../00_导航/03_进度看板.md` |

## 使用方式

1. 复制模板到你的笔记工具或本地记录文件。
2. 保留字段名，不要自创同义字段；否则周复盘无法汇总。
3. 每天只填当天的模板，不补写过去几天的流水账。
4. 模板本身保持空白；个人数据不要写回本目录。

## 字段对齐

- 三项评分统一为：听辨、跟读、流利度（0-10）。
- 错音标签统一为：`一级:二级`，见 [`../03_错题与复盘/问题标签说明.md`](../03_错题与复盘/问题标签说明.md)。
- 每日错音记录 1-3 条；每周主攻 3 个问题。
