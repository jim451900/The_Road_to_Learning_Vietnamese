# prompts

本目录保存生成课程时使用过的原始 AI 素材与提示词痕迹。

## 规则

1. **原始稿不是课程**：未校订的 AI 回答不得直接进入 `01_发音系统/04_每日任务_Day01-Day15.md`。
2. **先蒸馏再使用**：把可用内容整理进 `../02_句子积木/01_高频句型骨架.md`、`../02_句子积木/02_积木词库_最小可用.md` 或 `../语料库/`。
3. **标注状态**：每个原始文件顶部必须有“原始稿，未校订”的说明。
4. **不追求保留全部**：与现有规范重复或质量不足的内容，可以直接删除；git 历史仍可追溯。
