# 00_导航

先读哪一页，取决于你现在要回答的问题：

| 你要回答的问题 | 打开哪一页 |
|---|---|
| 这个阶段怎么学、每天怎么走、什么算学会 | [01_学习地图.md](01_学习地图.md) |
| 15 天之后还有多久、后面学什么 | [02_90天路线图.md](02_90天路线图.md) |
| 我现在第几天、哪里弱、下一步做什么 | [03_进度看板.md](03_进度看板.md) |

## 阅读顺序

1. 第一次进入：`../README.md` -> 本页 -> `01_学习地图.md`。
2. 每天开始：`03_进度看板.md` 确认当前 Day 与昨日遗留问题。
3. 每天结束：把结果写回 `03_进度看板.md` 与 `../03_错题与复盘/个人错音清单.md`。
4. 每周结束：填写 `../templates/03_每周复盘模板.md`，把结论写回看板。
5. Day15：按 `../01_发音系统/06_阶段测评_Day15.md` 测评，再决定是否进入下一阶段。

## 边界

- 本目录不承载具体词句；词句只来自 `../01_发音系统/04_每日任务_Day01-Day15.md`。
- 本目录不复制模板字段；模板只来自 `../templates/`。
- 本目录不记录个人错音明细；明细只来自 `../03_错题与复盘/个人错音清单.md`。
