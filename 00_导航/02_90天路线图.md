# 90 天路线图

## 先说明边界

- 本仓库当前**只完整实现 Phase 1（Day01-Day15）**。
- Phase 2-4 只定义目标、模块名与出口标准，**不预建空目录、不写空壳课程**。
- 编号规则：`00_导航`、`01_发音系统`、`02_句子积木`、`03_错题与复盘` 已存在；`04`-`08` 预留给后续阶段。这样当前地形没有编号空洞，未来扩展也有稳定位置。

## 四阶段总览

| 阶段 | Day | 主题 | 已建/计划模块 | 状态 |
|---|---|---|---|---|
| Phase 1 | 01-15 | 发音先行：字母、声调、元音、韵尾、声母对立 | `01_发音系统` + `02_句子积木` | 已实现 |
| Phase 2 | 16-45 | 语法骨架 + 高频场景对话 | `04_语法骨架` + `05_场景对话` | 计划中 |
| Phase 3 | 46-70 | 听力输入 + 阅读 | `06_听力输入` + `07_阅读` | 计划中 |
| Phase 4 | 71-90 | 输出、测评与个人语料沉淀 | `08_输出与测评` | 计划中 |

`03_错题与复盘` 是跨阶段支持层，不属于任何单一阶段，从 Day01 起持续使用。

## Phase 1：发音先行（Day01-Day15）

**目标**：建立北部标准发音的稳定口型、声调与高频词句输出。

**出口标准**：

- 听辨最小对立 >= 80%。
- 跟读评分 >= 7/10。
- 30-60 秒场景短述可懂。
- 产出问题清单 v2。

**当前入口**：[`01_学习地图.md`](01_学习地图.md)、[`../01_发音系统/README.md`](../01_发音系统/README.md)。

## Phase 2：语法骨架 + 场景对话（Day16-Day45）

**目标**：从“会读短句”升级到“能处理高频生活场景”。

**计划模块**：

- `04_语法骨架`：词序、时态粒子、否定、疑问、量词、比较、条件句、代词系统、介词/方位词；只讲高频规则，不做语法百科。
- `05_场景对话`：点餐、购物、问路、就医、租房、工作、社交；每个场景绑定听力输入与角色扮演任务。

**出口标准**：

- 能在 8 个高频场景完成 2-3 轮对话。
- 能正确使用 `đã/đang/sẽ`、`không`、`có ... không`、量词、常用连接词、称呼语与核心介词。
- 语法错误不影响可懂度。

**启动条件**：Phase 1 出口标准全部满足；届时再创建模块与 L2，不提前建空目录。

## Phase 3：听力输入 + 阅读（Day46-Day70）

**目标**：建立真实语速输入能力，开始从“学过的句子”转向“没学过的材料”。

**计划模块**：

- `06_听力输入`：分级听力、精听/泛听、听写、连读与弱读。
- `07_阅读`：短文本、标识、菜单、社交媒体贴文、简易新闻；积累被动词汇。

**出口标准**：

- 能听懂 1-2 分钟慢速真实材料并复述主旨。
- 能读懂 200 字左右的日常文本，生词率低于 10%。
- 建立个人听力/阅读素材库与生词本。

## Phase 4：输出与测评（Day71-Day90）

**目标**：把输入转成稳定输出，完成一次可量化的阶段测评。

**计划模块**：

- `08_输出与测评`：口语独白、复述、写作、90 天总测评与下一阶段计划。

**出口标准**：

- 能完成 2 分钟主题陈述。
- 能写 150-200 字日常短文。
- 形成个人语料库与下一阶段学习计划。

## 路线维护规则

1. 每进入一个新阶段，才创建对应模块目录、README 与 CLAUDE.md。
2. 新模块必须复用 `语料库/` 的 ID 规则与 `templates/` 的记录字段。
3. 任何阶段目标变化，先改本文件，再改 `01_学习地图.md` 与 `03_进度看板.md`。
