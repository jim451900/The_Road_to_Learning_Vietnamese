# 音节结构与拼写规则

这条文件解决两个问题：

1. 看到一个越南语词，知道它由哪几块组成。
2. 写一个词时，知道声调符号该放在哪个元音上。

## 1) 音节公式

越南语音节可以拆成五块，其中介音和韵尾可缺席：

```
声母 + 介音（可选） + 主元音 + 韵尾（可选） + 声调
Onset + medial (optional) + nucleus + coda (optional) + tone
```

例子：

| 词 | 声母 | 介音 | 主元音 | 韵尾 | 声调 |
|---|---|---|---|---|---|
| `ma` | m | - | a | - | ngang |
| `má` | m | - | a | - | sắc |
| `tiếng` | t | - | iê | ng | sắc |
| `nước` | n | - | ươ | c | sắc |
| `quà` | qu | - | a | - | huyền |
| `gia` | gi | - | a | - | ngang |
| `khuya` | kh | u | y | - | ngang |

> `qu` 和 `gi` 整体当声母看，不要把 `u` / `i` 当主元音。`quà` 的声调落在 `a`，`già` 的声调也落在 `a`。

## 2) 声母拼写规则

越南语用不同的字母组合表示同一个音，取决于后面的元音。记住三组“硬规则”：

### c / k / q

| 写法 | 出现在 | 例子 |
|---|---|---|
| `c` | 后接 `a, o, u` 或辅音 | `ca`, `cơm`, `của` |
| `k` | 后接 `i, e, ê` | `ki`, `kem`, `kê` |
| `q` | 只出现在 `qu` 组合 | `quà`, `quê`, `quy` |

### g / gh

| 写法 | 出现在 | 例子 |
|---|---|---|
| `g` | 后接 `a, o, u` | `ga`, `gọi`, `gửi` |
| `gh` | 后接 `i, e, ê` | `ghi`, `ghế`, `ghé` |

### ng / ngh

| 写法 | 出现在 | 例子 |
|---|---|---|
| `ng` | 后接 `a, o, u` | `nga`, `ngon`, `ngủ` |
| `ngh` | 后接 `i, e, ê` | `nghi`, `nghĩ`, `nghệ` |

一句话记忆：**i/e/ê 前用 k、gh、ngh；其余用 c、g、ng。**

## 3) 韵尾与声调限制

越南语的韵尾分两类：

- 鼻音韵尾：`-m, -n, -ng, -nh`
- 塞音韵尾：`-p, -t, -c, -ch`

关键规则：**以 `-p, -t, -c, -ch` 结尾的音节，只能出现 ngang、sắc、nặng 三个声调。**  
也就是说，塞音韵尾音节不会出现 huyền、hỏi、ngã。

| 韵尾 | 可用声调 | 例子 |
|---|---|---|
| `-m, -n, -ng, -nh` | 6 个声调 | `cơm`, `bàn`, `đang`, `nhanh` |
| `-p, -t, -c, -ch` | ngang / sắc / nặng | `gặp`, `bát`, `bác`, `sách` |

这条规则能帮你排除大量拼写错误：看到 `-p/-t/-c/-ch` 上有 hỏi 或 ngã，基本可以判错。

## 4) 声调符号放在哪个元音

按优先级执行，三步即可覆盖绝大多数词：

### 第一步：优先标在“带质量符号”的元音上

`ă, â, ê, ô, ơ, ư` 是带质量符号的元音。只要音节里有它们，声调就标在它们上面。

| 词 | 带符号元音 | 声调位置 |
|---|---|---|
| `cần` | â | `ầ` |
| `tốt` | ô | `ố` |
| `mở` | ơ | `ở` |
| `tử` | ư | `ử` |
| `tiếng` | ê | `ế` |
| `muốn` | ô | `ố` |
| `được` | ơ | `ợ` |

### 第二步：没有质量符号，且有韵尾 → 标在最后一个元音

| 词 | 韵尾 | 声调位置 |
|---|---|---|
| `bạn` | n | `ạ` |
| `học` | c | `ọ` |
| `nhanh` | nh | `a` |
| `mạnh` | nh | `ạ` |

### 第三步：没有质量符号，且是开音节 → 标在第一个元音

| 词 | 元音组合 | 声调位置 |
|---|---|---|
| `cái` | a + i | `á` |
| `màu` | a + u | `à` |
| `của` | u + a | `ủ` |
| `mía` | i + a | `í` |
| `múa` | u + a | `ú` |
| `mời` | ơ + i | `ờ`（第一步已覆盖） |
| `mây` | â + y | `â`（第一步已覆盖） |

### 特殊情况

- `qu` / `gi` 整体是声母：`quà`、`quê`、`già`、`giờ`。
- `gì` 的 `i` 是主元音，声调标在 `i` 上：`gì`。
- `oa / oe / uy` 等组合存在拼写变体（如 `hòa` / `hoà`），以词典写法为准，不要自行类推。

## 6) 常见拼写错误清单

- 把 `cơm` 写成 `côm`：`ơ` 和 `ô` 是两个不同的元音。
- 把 `người` 写成 `ngừơi`：声调只标一个元音，且标在 `ơ` 上。
- 把 `quà` 写成 `qùa`：`qu` 是声母，声调在 `a`。
- 把 `già` 写成 `gìa`：`gi` 是声母，声调在 `a`。
- 在 `-p/-t/-c/-ch` 音节上写 hỏi/ngã：违反塞音韵尾限制。
