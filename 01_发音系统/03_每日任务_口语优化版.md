# 每日任务（Day01-Day15，口语优化版）

说明：这版在保留发音训练目标的同时，优先使用更高频、更自然的口语词句。

## Day01 基线与开口

词包（VI / CN / EN）：
- `xin chào` / 你好 / hello
- `tôi` / 我 / I
- `bạn` / 你；朋友 / you; friend
- `tên` / 名字 / name
- `là` / 是 / be
- `đến từ` / 来自 / come from
- `Trung Quốc` / 中国 / China
- `học` / 学 / study
- `tiếng Việt` / 越南语 / Vietnamese
- `cảm ơn` / 谢谢 / thank you

口语句：
- `Xin chào, tôi tên là ...` / 你好，我叫... / Hi, my name is ...
- `Tôi đến từ Trung Quốc.` / 我来自中国。 / I am from China.
- `Tôi học tiếng Việt.` / 我在学越南语。 / I am learning Vietnamese.
- `Bạn khỏe không?` / 你好吗？ / How are you?
- `Cảm ơn bạn.` / 谢谢你。 / Thank you.

## Day15 阶段测评与总结

词包：
- `tiến bộ` / 进步 / progress
- `vấn đề` / 问题 / issue
- `cải thiện` / 改善 / improve
- `mục tiêu` / 目标 / goal
- `tiếp tục` / 继续 / continue
- `ổn định` / 稳定 / stable
- `thói quen` / 习惯 / habit
- `giao tiếp` / 交流 / communicate
- `tự tin` / 自信 / confident
- `kế hoạch` / 计划 / plan

口语句：
- `Tôi đã tiến bộ nhiều.` / 我进步了很多。 / I improved a lot.
- `Vấn đề lớn nhất của tôi là thanh điệu.` / 我最大的问题是声调。 / My biggest issue is tones.
- `Tôi cần cải thiện âm cuối.` / 我需要改善韵尾。 / I need to improve final sounds.
- `Mục tiêu của tôi là giao tiếp tự tin.` / 我的目标是自信交流。 / My goal is confident communication.
- `Tôi sẽ tiếp tục theo kế hoạch.` / 我会继续按计划练习。 / I will continue with the plan.
