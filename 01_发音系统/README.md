# 15天北部标准发音总计划（音词一体化）

## 计划规则

- Day01 先做基线测试：[05_基线测试.md](05_基线测试.md)。
- 先完成字母总览：[01_越南语字母总览_对比英语.md](01_越南语字母总览_对比英语.md)。
- 先完成声调总览：[02_越南语声调总览_日常表达对比.md](02_越南语声调总览_日常表达对比.md)。
- 补齐音节结构：[07_音节结构与拼写规则.md](07_音节结构与拼写规则.md)，知道声调该标在哪。
- 每天：1个发音主题 + 10个高频词 + 5个实用句 + 1段微场景。
- 每天必须录音（30-60秒）。
- 第二天先复习前一天的错音，再学新内容。
- 唯一词句来源：[04_每日任务_Day01-Day15.md](04_每日任务_Day01-Day15.md)。

## 日程总览

- Day01：字母总览 + 声调总览 + 基线测试 + 音节结构入门
- Day02：A组 `a, ă, â`
- Day03：E组 `e, ê`
- Day04：O组 `o, ô, ơ`
- Day05：易组 `i/y, u, ư`
- Day06：复合元音 I `ai, ao, au, âu, ay, ây`
- Day07：复合元音 II `ia/iê, ua/uô, ưa/ươ`
- Day08：韵尾 `-m, -n, -ng, -nh, -p, -t, -c/-ch`
- Day09：声调 I `ngang, huyền, sắc`
- Day10：声调 II `hỏi, ngã, nặng`
- Day11：六声调整合与同音节轮读
- Day12：声母对立 I `tr/ch, s/x`
- Day13：声母对立 II `r, d, gi` 和 `l/n`
- Day14：语流与句子节奏
- Day15：阶段测评 + 发音问题清单 v2

## 建议执行节奏

- 低负荷日：保底完成听辨 + 跟读 + 10词。
- 正常日：完成完整 4 步流程。
- 高效日：加做 1 轮微场景复述。
