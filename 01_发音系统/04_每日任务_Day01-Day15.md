# 每日任务（Day01-Day15，唯一事实源）

说明：每天执行同一结构。

- 发音主题：当天要攻的音点与最小对立。
- 发音 drill：5-10 个专门练口的词，允许是低频词或练调词。
- 高频词 10 个：进入长期记忆的可用词（VI / CN / EN）。
- 实用句 5 个：当天必须能不看中文说出的句子（VI / CN / EN）。
- 微场景 1 个：20-60 秒输出任务，必须录音。

> 修改规则：改词句只改本文件，然后运行 `make corpus`。不要直接改 `语料库/`。

## Day01 基线与开口

> 音点：字母总览 + 6 声调体感 + 音节结构入门
> 常见错误：中文母语者易把 ư 读成 u；声调只在单词上读，进句子就丢调。
> 最小对立：tu / tư；ma / mà / má / mả / mã / mạ

### 发音 drill

- `tôi` / 我 / I
- `bạn` / 你；朋友 / you; friend
- `ăn` / 吃 / eat
- `uống` / 喝 / drink
- `đi` / 去 / go

### 高频词

- `xin chào` / 你好 / hello
- `tôi` / 我 / I
- `bạn` / 你；朋友 / you; friend
- `tên` / 名字 / name
- `là` / 是 / be
- `đến từ` / 来自 / come from
- `Trung Quốc` / 中国 / China
- `học` / 学 / study
- `tiếng Việt` / 越南语 / Vietnamese
- `cảm ơn` / 谢谢 / thank you

### 实用句

- `Xin chào, tôi tên là ...` / 你好，我叫... / Hi, my name is ...
- `Tôi đến từ Trung Quốc.` / 我来自中国。 / I am from China.
- `Tôi học tiếng Việt.` / 我在学越南语。 / I am learning Vietnamese.
- `Bạn khỏe không?` / 你好吗？ / How are you?
- `Cảm ơn bạn.` / 谢谢你。 / Thank you.

### 微场景

做 30 秒自我介绍：姓名、来自哪里、在学越南语。录音后回听，标出最不稳的 1-2 个音。

## Day02 A组 `a, ă, â`

> 音点：A 组 `a, ă, â`
> 常见错误：a/ă/â 混淆；ă 不够短，â 读得过开。
> 最小对立：an / ăn / ân；căn / cân

### 发音 drill

- `ba` / 三；爸爸 / three; father
- `ăn` / 吃 / eat
- `cần` / 需要 / need
- `mặt` / 脸 / face
- `bận` / 忙 / busy

### 高频词

- `ăn` / 吃 / eat
- `cảm ơn` / 谢谢 / thank you
- `bạn` / 你；朋友 / you; friend
- `bận` / 忙 / busy
- `rảnh` / 空闲 / free
- `gặp` / 见面 / meet
- `cần` / 需要 / need
- `năm` / 年；五 / year; five
- `hằng ngày` / 每天 / every day
- `thẳng` / 直 / straight

### 实用句

- `Hôm nay tôi bận.` / 我今天忙。 / I am busy today.
- `Khi nào bạn rảnh?` / 你什么时候有空？ / When are you free?
- `Tôi cần bạn giúp.` / 我需要你帮忙。 / I need your help.
- `Hẹn gặp bạn nhé.` / 约好见。 / See you then.

### 微场景

## Day06 复合元音 I

> 音点：`ai, ao, au, âu, ay, ây`
> 常见错误：复合元音读成两个独立音节。
> 最小对立：ai / ay；ao / au

### 发音 drill

- `ai` / 谁 / who
- `sao` / 怎么 / how
- `rau` / 蔬菜 / vegetables
- `đau` / 疼 / hurt
- `đây` / 这里 / here

### 高频词

- `ai` / 谁 / who
- `nào` / 哪个 / which
- `sao` / 怎么 / how
- `đau` / 疼 / hurt
- `rau` / 蔬菜 / vegetables
- `đây` / 这里 / here
- `đấy` / 那里（口语提示） / there (spoken)
- `thấy` / 看见 / see
- `quầy` / 柜台 / counter
- `ngay` / 马上 / right away

### 实用句

- `Ai đây?` / 这是谁？ / Who is this?
- `Bạn thấy sao?` / 你觉得怎么样？ / What do you think?
- `Tay tôi hơi đau.` / 我手有点疼。 / My hand hurts a bit.

### 微场景

## Day14 语流与节奏

> 音点：短句连读、停顿、重音、句尾收束
> 常见错误：停顿和句尾收束不自然。
> 最小对立：节奏组：hôm nay / ngày mai；đúng / sai

### 发音 drill

- `hôm nay` / 今天 / today
- `ngày mai` / 明天 / tomorrow
- `đúng` / 对 / correct
- `sai` / 错 / wrong
- `xin lỗi` / 对不起 / sorry

### 高频词

- `hôm nay` / 今天 / today
- `ngày mai` / 明天 / tomorrow
- `thường` / 经常 / often
- `đôi khi` / 有时 / sometimes
- `xin lỗi` / 对不起 / sorry
- `không sao` / 没关系 / no problem
- `một chút` / 一点 / a little
- `được` / 可以；得到 / can; get
- `đúng rồi` / 对了 / that is right
- `thế à` / 是吗 / is that so

### 实用句

- `Hôm nay tôi đi học, ngày mai tôi đi làm.` / 今天我学习，明天我工作。 / I study today and work tomorrow.
- `Bạn nói chậm một chút được không?` / 你能说慢一点吗？ / Could you speak a bit slower?
- `Xin lỗi, tôi chưa hiểu.` / 抱歉，我还没听懂。 / Sorry, I do not understand yet.
- `Không sao, nói lại nhé.` / 没关系，再说一次吧。 / No problem, say it again.
- `Đúng rồi, cảm ơn bạn.` / 对的，谢谢你。 / Exactly, thank you.

### 微场景

完整 40 秒日常陈述：今天做什么、明天做什么、请求对方说慢一点。录音。

## Day15 阶段测评与总结

> 音点：综合复盘，按测评结果定位
> 常见错误：综合复盘；不要只报“还不行”，要定位到具体音点。
> 最小对立：全阶段最小对立抽测

### 发音 drill

- `tiến bộ` / 进步 / progress
- `vấn đề` / 问题 / issue
- `luyện` / 练习 / practice
- `tiếp tục` / 继续 / continue
- `tự tin` / 自信 / confident

### 高频词

- `tiến bộ` / 进步 / progress
- `vấn đề` / 问题 / issue
- `cải thiện` / 改善 / improve
- `mục tiêu` / 目标 / goal
- `tiếp tục` / 继续 / continue
- `ổn định` / 稳定 / stable
- `thói quen` / 习惯 / habit
- `giao tiếp` / 交流 / communicate
- `tự tin` / 自信 / confident
- `kế hoạch` / 计划 / plan

### 实用句

- `Tôi đã tiến bộ nhiều.` / 我进步了很多。 / I improved a lot.
- `Vấn đề lớn nhất của tôi là thanh điệu.` / 我最大的问题是声调。 / My biggest issue is tones.
- `Tôi cần cải thiện âm cuối.` / 我需要改善韵尾。 / I need to improve final sounds.
- `Mục tiêu của tôi là giao tiếp tự tin.` / 我的目标是自信交流。 / My goal is confident communication.
- `Tôi sẽ tiếp tục theo kế hoạch.` / 我会继续按计划练习。 / I will continue with the plan.

### 微场景

做 60 秒阶段总结：进步点、最大难点、下步计划。按 `06_阶段测评_Day15.md` 评分。
