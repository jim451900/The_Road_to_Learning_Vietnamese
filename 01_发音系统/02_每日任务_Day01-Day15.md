# 每日任务（Day01-Day15）

说明：每一天都执行同一结构。
- 发音主题
- 高频词 10 个（VI / CN / EN）
- 实用句 5 个（VI / CN / EN）
- 微场景 1 个（20-40 秒）

---

## Day01 基线测试与入门

前置：先阅读 [01_发音系统/00_越南语字母总览_对比英语.md](00_越南语字母总览_对比英语.md)，确认“29字母 vs 英语26字母”的差异。
前置：再阅读 [01_发音系统/00_越南语声调总览_日常表达对比.md](00_越南语声调总览_日常表达对比.md)，用“你好/谢谢/对不起/再见/多少钱”建立声调体感。

高频词：
- `tôi` / 我 / I
- `bạn` / 朋友；你 / friend; you
- `là` / 是 / be
- `ăn` / 吃 / eat
- `uống` / 喝 / drink
- `nước` / 水 / water
- `cơm` / 米饭 / rice
- `nhà` / 家 / home
- `đi` / 去 / go
- `đến` / 来，到 / come; arrive

实用句：
- `Tôi là ...` / 我是... / I am ...
- `Tôi ăn cơm.` / 我吃饭。 / I eat rice.
- `Tôi uống nước.` / 我喝水。 / I drink water.
- `Tôi đi học.` / 我去学习。 / I go study.
- `Bạn khỏe không?` / 你好吗？ / How are you?

微场景：做 30 秒自我介绍（姓名、来自哪里、在学越南语）。

加做 5 分钟：
- 口头回答：越南语少了哪4个英文字母？
- 口头回答：越南语多了哪7个字母？
- 口头串读：`Xin chào -> Cảm ơn -> Xin lỗi -> Tạm biệt -> Bao nhiêu tiền?`
