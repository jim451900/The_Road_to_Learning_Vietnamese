# 元音分类记忆（北部标准）

目标：通过 A/E/O/易组分类，快速建立口型-舌位-音色映射。

## A组：`a, ă, â`

- `a`：开口较大，音值较饱满。
- `ă`：更短更快，短促收束。
- `â`：中性中央化，常被中文母语者读得过开。

示例词（VI / CN / EN）：
- `ba` / 三；爸爸 / three; father
- `ăn` / 吃 / eat
- `cần` / 需要 / need

## E组：`e, ê`

- `e`：较开前元音。
- `ê`：更紧更高，避免与 `e` 混读。

示例词：
- `em` / 你（晚辈） / younger person; you (younger)
- `tên` / 名字 / name
- `đến` / 来，到达 / come; arrive

## O组：`o, ô, ơ`

- `o`：开口相对更开，圆唇。
- `ô`：更闭更聚焦，圆唇更明显。
- `ơ`：中后位置，唇形相对更放松。

示例词：
- `to` / 大 / big
- `tốt` / 好 / good
- `ở` / 在，住 / be at; live

## 易组：`i/y, u, ư`

- `i/y`：读音接近，先按同音处理。
- `u`：后高圆唇。
- `ư`：后高不圆唇，中文母语者常误读为 `u`。

示例词：
- `đi` / 去 / go
- `uống` / 喝 / drink
- `từ` / 从；词 / from; word

## 训练原则

- 先组内对比，再跨组对比。
- 每个音点至少绑定 3 个高频词。
- 任何字母练习都要落到词和句，不做孤立机械背诵。
