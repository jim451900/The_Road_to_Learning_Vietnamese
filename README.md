# 越南语学习之路（CN/EN/VI）

这是一个面向中文母语者（懂英语）的越南语自学手册工程。

当前版本先聚焦 **北部标准发音**，采用 **15天音词一体化计划**：
- 不死记字母，按发音分类学习（A/E/O/易组）
- 每天绑定高频词和实用句
- 通过听辨、跟读、录音和场景输出形成闭环

## 使用方式

1. 先看 `00_导航/学习地图.md` 明确目标和规则。
2. 每天按 `01_发音系统/02_每日任务_Day01-Day15.md` 执行。
3. 用 `templates/发音打卡模板.md` 记录问题，第二天先纠错再学新内容。
4. Day15 做阶段测评，产出自己的发音问题清单 v2。

## 学习原则

- **音词一体化**：每个音点配高频词和场景句。
- **先辨后说**：先听辨，再跟读，再输出。
- **少量高频重复**：每天只攻 1-2 个关键问题。
- **北部标准优先**：先稳定标准发音，再了解地区变体。
