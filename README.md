# 越南语学习之路（CN/EN/VI）

面向中文母语者（懂英语）的越南语自学系统。

当前版本完整实现 **15 天北部标准发音阶段**，并把 15 天放进明确的 90 天长期路线中。后续阶段只定义目标与入口，不预建空壳课程。

## 快速开始

1. 先读 [`00_导航/01_学习地图.md`](00_导航/01_学习地图.md)，明确阶段目标与每日链路。
2. 做 [`01_发音系统/05_基线测试.md`](01_发音系统/05_基线测试.md)，留下起点数据。
3. 每天按 [`01_发音系统/04_每日任务_Day01-Day15.md`](01_发音系统/04_每日任务_Day01-Day15.md) 执行 10 词 + 5 句 + 微场景。
4. 用 [`templates/01_发音打卡模板.md`](templates/01_发音打卡模板.md) 记录，并把结果写回 [`00_导航/03_进度看板.md`](00_导航/03_进度看板.md)。
5. 每天把错音写进 [`03_错题与复盘/个人错音清单.md`](03_错题与复盘/个人错音清单.md)，每周做一次复盘。
6. Day15 按 [`01_发音系统/06_阶段测评_Day15.md`](01_发音系统/06_阶段测评_Day15.md) 测评，再决定是否进入 Phase 2。

## 执行闭环

```
学习地图定目标
  -> 每日任务执行
  -> 模板记录
  -> 错题复盘
  -> 进度看板调优
  -> 回到每日任务
```

闭环中的每个节点都有可填写的数据结构：

- 目标：[`00_导航/01_学习地图.md`](00_导航/01_学习地图.md)
- 状态：[`00_导航/03_进度看板.md`](00_导航/03_进度看板.md)
- 记录：[`templates/`](templates/README.md)
- 数据：[`03_错题与复盘/`](03_错题与复盘/README.md)
- 索引：[`语料库/`](语料库/README.md)

## 单一事实源

- 每日词句只在 [`01_发音系统/04_每日任务_Day01-Day15.md`](01_发音系统/04_每日任务_Day01-Day15.md) 维护。
- [`语料库/`](语料库/README.md) 三个数据文件由 `make corpus` 生成，禁止手改。
- 联动示范、复盘清单只引用句库 ID，不重抄 10 句清单。
- 这样改一个词只需要改一处，再跑一次生成器。

## 质量门禁

```bash
make check    # 检查断链、孤岛、L2/L3、15 天每日 10 词 5 句、语料库同步
make corpus   # 重新生成语料库
make audio    # 用 macOS 越南语语音 Linh 生成本地兜底音频
```

当前门禁覆盖：

- 零断链。
- 零孤岛文件。
- 每个模块有 `CLAUDE.md`。
- 每个业务 Markdown 有 `INPUT/OUTPUT/POS/PROTOCOL` 头部。
- Day01-Day15 每天恰好 10 个高频词、5 个实用句、至少 3 个 drill、1 个微场景。
- `语料库/` 与唯一事实源同步。
- 单文件不超过 800 行。

## 学习原则

- **音词一体化**：每个音点配高频词和场景句。
- **先辨后说**：先听辨，再跟读，再输出。
- **少量高频重复**：每天只攻 1-2 个关键问题。
- **北部标准优先**：先稳定标准发音，再了解地区变体。
- **数据驱动纠偏**：每天记录，每周只保留 3 个主攻问题。
