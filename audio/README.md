# 音频协议

发音课没有音频，就像数学课没有数字。这个目录定义音频从哪来、怎么命名、怎么用。

## 目录结构

```
audio/
├── README.md
├── CLAUDE.md
├── Day01/
│   ├── W01-01_toi.aiff
│   ├── W01-02_ban.aiff
│   └── S01-01.aiff
├── Day02/
└── ...
recordings/
└── Day01/
    └── my_30s_intro.m4a
```

- `audio/DayNN/`：输入音频（母语者、词典、TTS）。
- `recordings/DayNN/`：你自己的录音。
- 两者都被 `.gitignore` 忽略，只保留协议文件。不要把大文件提交进仓库。

## 命名规则

- 词：`W{Day}-{序号}_{ASCII slug}.aiff`，例如 `W01-01_toi.aiff`。
- 句：`S{Day}-{序号}.aiff`，序号与 `../语料库/02_句库.md` 的句子 ID 一致。
- 录音：`recordings/DayNN/{用途}_{YYYY-MM-DD}.m4a`，例如 `recordings/Day01/self_intro_2026-10-17.m4a`。

## 音频来源（按优先级）

1. **母语者现场读**：最可靠，能纠正语调与连读。
2. **真人词典发音**：Forvo、Wiktionary 等，适合单词与短句。
3. **系统 TTS（兜底）**：macOS 自带越南语语音 `Linh`（`vi_VN`）。

### 用 macOS 批量生成兜底音频

```bash
# 生成全部 15 天的词句
make audio

# 只生成某一天
python3 scripts/generate_audio.py --day 1
```

生成的文件进入 `audio/DayNN/`，不会提交到 git。TTS 只用于辨音和跟读起点，**不要把它当作语调模仿的最终标准**。

## 每日听辨流程（10 分钟）

1. 打开当天 `audio/DayNN/`，先听 10 个高频词，每个词听 2 遍。
2. 听 5 个实用句，先不看文本，判断有几个声调/音点听不清。
3. 打开 [`../01_发音系统/04_每日任务_Day01-Day15.md`](../01_发音系统/04_每日任务_Day01-Day15.md) 对照文本，再听 1 遍。
4. 用 [`../01_发音系统/05_基线测试.md`](../01_发音系统/05_基线测试.md) 的最小对立做 5 组听辨。
5. 把听不清的词写入 [`../03_错题与复盘/个人错音清单.md`](../03_错题与复盘/个人错音清单.md)。

## 每日录音流程（5-10 分钟）

1. 录音 30-60 秒，内容按当天微场景。
2. 回听时只关注 1-2 个音点，不要一次改所有问题。
3. 把录音文件名写入 [`../templates/01_发音打卡模板.md`](../templates/01_发音打卡模板.md)。
4. 把最不稳的 1-3 个点写入错音清单。

## 隐私与体积

- 录音默认只留在本地，不提交。
- 如果要在多设备同步，使用你自己的私有存储，不要放进公开仓库。
- `.gitignore` 已忽略 `audio/Day*/` 与 `recordings/`。
