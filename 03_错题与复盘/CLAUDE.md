# 03_错题与复盘/
> L2 | 父级: ../CLAUDE.md

## 职责
跨阶段的个人学习数据层：沉淀错音、统一标签、按周复盘，并把结果反馈给进度看板与每日任务。
这里记录的是“我的数据”，不是课程内容；课程内容仍以 `01_发音系统/04_每日任务_Day01-Day15.md` 为准。

## 成员清单
- `README.md`: 复盘系统的使用规则与每日/每周节奏。
- `个人错音清单.md`: 按日期与标签记录的错音明细，含现象、纠偏动作、状态。
- `每周复盘.md`: Week1、Week2 与 Day15 阶段复盘记录，只保留最影响交流的 3 个问题。
- `问题标签说明.md`: 一级/二级标签规范，以及“同类错误 3 次升级”的判定规则。

## 依赖与暴露
- 上游：`../00_导航/03_进度看板.md` 定义每日记录节奏；`../01_发音系统/08_中文母语者高频错误对照.md` 提供标签与纠偏动作。
- 下游：复盘结果回流到 `../00_导航/03_进度看板.md` 的“下一步”决策，并决定次日/下周主攻点。
- 数据方向：每日错音 -> 周复盘 Top 3 -> 进度看板下一步；不反向修改课程内容。
