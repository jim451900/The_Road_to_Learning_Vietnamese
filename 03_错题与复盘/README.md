# 错题与复盘系统

这个目录用于沉淀你的个人发音问题，不追求一次学会，追求可持续纠偏。

## 文件说明

- [个人错音清单.md](个人错音清单.md)：按音点记录高频错误与纠偏策略
- [每周复盘.md](每周复盘.md)：每 7 天复盘一次，决定下周优先级
- [问题标签说明.md](问题标签说明.md)：统一错误分类标签，避免记录混乱

## 使用规则

1. 每天训练后记录 **1-3 条**错音：最低 1 条，最多 3 条，不要为凑数。
2. 每条错音必须带 `一级:二级` 标签，例如 `元音:u_vs_ư`；标签从 [问题标签说明.md](问题标签说明.md) 里选。
3. 同类错误累计出现 3 次，升级为“重点问题”，进入下周主攻候选。
4. 每周复盘只保留最影响交流的 **3 个问题**作为下周主攻，其余显式写进“暂缓”。
5. Day15 把最影响交流的 3 个问题整理成“问题清单 v2”，模板见 [`../01_发音系统/06_阶段测评_Day15.md`](../01_发音系统/06_阶段测评_Day15.md)。
