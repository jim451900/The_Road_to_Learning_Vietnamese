# 个人错音清单

使用方式：每天训练后新增一条；每周复盘时更新状态。

| 日期 | 标签 | 错误词/句 | 现象 | 纠偏动作 | 状态 |
|---|---|---|---|---|---|
| （示例）2026-03-29 | 元音:u_vs_ư | `từ` | 常读成 `tu` | 慢速对比 `u/ư` 20 次 + 5 句带词输出 | 进行中 |
| | | | | | |

> 第一行是示例，填写时保留或删除都可以；第二行是空白模板。每天写 1-3 条，最低 1 条。

## 状态定义

- `进行中`：本周还不稳定
- `已改善`：明显进步但偶发错误
- `已稳定`：连续 7 天基本无误

## 每日最少记录项

- 至少 1 个“最不稳词”
- 至少 1 个“对应纠偏动作”
- 至少 1 个规范标签（`一级:二级`，见 [问题标签说明.md](问题标签说明.md)）
- 最多记录 3 条；超过 3 条说明当天没有做优先级判断
