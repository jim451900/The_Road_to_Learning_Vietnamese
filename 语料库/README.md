# 语料库

本目录是课程内容的**规范化索引**，不是作者面。

## 唯一事实源

所有词句内容只在 [`../01_发音系统/04_每日任务_Day01-Day15.md`](../01_发音系统/04_每日任务_Day01-Day15.md) 中维护。  
本目录的三个数据文件由脚本生成：

```bash
make corpus   # 重新生成
make check    # 校验是否与源文件同步
```

## 文件

| 文件 | 内容 | ID 规则 |
|---|---|---|
| [01_词表.md](01_词表.md) | 去重后的词条，含中文、English、首次出现、出现次数 | `W{首次出现 Day}-{当日序号}` |
| [02_句库.md](02_句库.md) | 去重后的句子，含中文、English、Day、标签 | `S{Day}-{序号}` |
| [03_音点表.md](03_音点表.md) | 15 天音点、发音 drill、常见错误、最小对立 | 按 Day |

## 使用方式

- 查一个词的规范写法与首次出现：看 `01_词表.md`。
- 引用某一天的句子：用 `02_句库.md` 的 `S{Day}-{序号}`，不要重抄整句。
- 做听辨/纠偏：看 `03_音点表.md` 的最小对立与常见错误。
- 做音频：`make audio`，文件命名直接复用 `W` / `S` ID。

## 禁止事项

- 不要直接编辑三个数据文件；下次 `make corpus` 会覆盖。
- 不要在 `02_句子积木/` 或复盘页里另起一套词表。
- 不要手改 ID；ID 由生成器按每日任务顺序分配。

## 一致性

`../scripts/check_docs.py` 会重新生成三个文件并与磁盘内容比较；不同步时 `make check` 失败。
