# Day06-Day10 联动示范（发音 + 积木表达）

目标：进入复合元音、韵尾、声调阶段后，继续维持可输出表达，不让训练变成纯技术练习。

## Day06（复合元音 I）

### 发音重点

- 重点：`ai, ao, au, âu, ay, ây`
- 核心词：`ai`, `sao`, `rau`, `đau`, `đây`

### 积木骨架

- `Ai [động từ]?`
- `Bạn thấy [thế nào/sao]?`
- `Tôi [động từ] ngay.`

### 10句示例

1. `Ai đây?` / 这是谁？ / Who is this?
2. `Bạn thấy sao?` / 你觉得怎样？ / What do you think?
3. `Tôi mua rau.` / 我买菜。 / I buy vegetables.
4. `Tay tôi hơi đau.` / 我手有点疼。 / My hand hurts a bit.
5. `Quầy này ở đây.` / 柜台在这里。 / The counter is here.
6. `Bạn làm ngay nhé.` / 你马上做吧。 / Please do it right away.
7. `Tôi đi ngay.` / 我马上去。 / I will go right away.
8. `Ai nói câu này?` / 谁说这句话？ / Who said this sentence?
9. `Món này sao đắt vậy?` / 这个怎么这么贵？ / Why is this so expensive?
10. `Tôi thấy ổn.` / 我觉得还行。 / I think it is okay.

## Day07（复合元音 II）

### 发音重点

- 重点：`ia/iê, ua/uô, ưa/ươ`
- 核心词：`tiếng`, `muốn`, `nước`, `đường`, `thường`

### 积木骨架

- `Tôi học [ngôn ngữ].`
- `Tôi muốn [động từ/名词].`
- `Tôi thường [động词].`

### 10句示例

1. `Tôi học tiếng Việt.` / 我学越南语。 / I study Vietnamese.
2. `Tôi muốn mua nước.` / 我想买水。 / I want to buy water.
3. `Con đường này đi đâu?` / 这条路通向哪里？ / Where does this road go?
4. `Buổi trưa tôi thường nghỉ.` / 中午我通常休息。 / I usually rest at noon.
5. `Bạn đưa tôi cái này nhé.` / 把这个递给我吧。 / Please hand me this.
6. `Tôi muốn học thêm.` / 我想多学一点。 / I want to study more.
7. `Nước này lạnh.` / 这水是冷的。 / This water is cold.
8. `Từ này khó.` / 这个词难。 / This word is hard.
9. `Tôi thường đọc sách.` / 我经常读书。 / I often read books.
10. `Trưa nay tôi bận.` / 今天中午我忙。 / I am busy at noon.

## Day08（韵尾）

### 发音重点

- 重点：`-m, -n, -ng, -nh, -p, -t, -c/-ch`
- 核心词：`cơm`, `đang`, `nhanh`, `rất`, `thích`

### 积木骨架

- `Tôi đang [động词].`
- `Tôi rất [thích/bận/mệt].`
- `Nói [chậm/nhanh] thôi.`

### 10句示例

1. `Tôi đang học.` / 我正在学。 / I am studying.
2. `Tôi đang ăn cơm.` / 我正在吃饭。 / I am eating rice.
3. `Nói chậm thôi nhé.` / 请说慢一点。 / Please speak slowly.
4. `Bạn nói nhanh quá.` / 你说太快了。 / You speak too fast.
5. `Tôi rất thích sách này.` / 我很喜欢这本书。 / I really like this book.
6. `Hôm nay tôi gặp bạn.` / 今天我见你。 / I meet you today.
7. `Tôi học mỗi ngày.` / 我每天学习。 / I study every day.
8. `Âm cuối này khó.` / 这个韵尾很难。 / This final sound is hard.
9. `Bạn đọc lại giúp tôi.` / 你再读一遍给我听。 / Please read it again.
10. `Tôi luyện chậm trước.` / 我先慢练。 / I practice slowly first.

## Day09（声调 I）

### 发音重点

- 重点：`ngang, huyền, sắc`
- 核心词：`cá`, `cà phê`, `ba`, `bà`, `đá`

### 积木骨架

- `Tôi [ăn/uống] [名词].`
- `... này [形容词].`
- `[数量] [名词].`

### 10句示例

1. `Tôi uống cà phê đá.` / 我喝冰咖啡。 / I drink iced coffee.
2. `Tôi ăn cá.` / 我吃鱼。 / I eat fish.
3. `Ba ngày nữa.` / 三天后。 / In three days.
4. `Bà ở nhà.` / 她在家。 / She is at home.
5. `Món này ngon.` / 这个菜好吃。 / This dish is tasty.
6. `Tôi đi chợ.` / 我去市场。 / I go to market.
7. `Bạn về chưa?` / 你回去了吗？ / Have you gone home?
8. `Tôi đến rồi.` / 我到了。 / I arrived.
9. `Đá tan nhanh.` / 冰化得快。 / Ice melts quickly.
10. `Cà phê này đắng.` / 这咖啡苦。 / This coffee is bitter.

## Day10（声调 II）

### 发音重点

- 重点：`hỏi, ngã, nặng`
- 核心词：`hỏi`, `ngã`, `nặng`, `rõ`, `sửa`

### 积木骨架

- `Tôi muốn hỏi [内容].`
- `Cái này [nặng/nhẹ].`
- `Bạn [nói/sửa] lại giúp tôi.`

### 10句示例

1. `Tôi muốn hỏi một câu.` / 我想问一个问题。 / I want to ask a question.
2. `Cái túi này nặng quá.` / 这个包太重了。 / This bag is too heavy.
3. `Bạn nói lại cho rõ nhé.` / 你再说清楚一点。 / Please say it clearly again.
4. `Giúp tôi sửa câu này.` / 帮我改这句话。 / Help me correct this sentence.
5. `Tôi nghe chưa rõ.` / 我还没听清。 / I cannot hear clearly yet.
6. `Từ này tôi đọc sai.` / 这个词我读错了。 / I pronounced this word wrong.
7. `Bạn hỏi lại đi.` / 你再问一次吧。 / Ask again.
8. `Tôi ngã rồi.` / 我摔倒了。 / I fell down.
9. `Bài này khó quá.` / 这课太难了。 / This lesson is too hard.
10. `Tôi vẫn tiếp tục luyện.` / 我还是继续练。 / I still continue practicing.
