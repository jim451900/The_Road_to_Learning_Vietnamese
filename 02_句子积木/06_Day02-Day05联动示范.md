# Day02-Day05 联动示范（发音 + 积木表达）

目标：在发音训练继续推进的同时，把 A/E/O/易组四类音点快速转成可复用表达。

## Day02（A组 `a, ă, â`）

### 发音重点

- 重点区分：`a`（开）、`ă`（短快）、`â`（中性央元音）
- 核心词：`ăn`, `bận`, `cần`, `gặp`, `rất`

### 积木骨架

- `Hôm nay tôi [trạng thái].`
- `Tôi cần [danh từ/hỗ trợ].`
- `Khi nào bạn [rảnh]?`

### 10句示例（VI / CN / EN）

1. `Hôm nay tôi bận.` / 我今天忙。 / I am busy today.
2. `Tôi cần nước.` / 我需要水。 / I need water.
3. `Tôi cần bạn giúp.` / 我需要你帮忙。 / I need your help.
4. `Khi nào bạn rảnh?` / 你什么时候有空？ / When are you free?
5. `Hẹn gặp bạn nhé.` / 回头见。 / See you.
6. `Tôi ăn cơm.` / 我吃饭。 / I eat rice.
7. `Tôi ăn sáng rồi.` / 我吃过早餐了。 / I had breakfast already.
8. `Tôi rất bận hôm nay.` / 我今天很忙。 / I am very busy today.
9. `Bạn ăn chưa?` / 你吃了吗？ / Have you eaten?
10. `Tôi cần thêm thời gian.` / 我还需要一点时间。 / I need more time.

## Day03（E组 `e, ê`）

### 发音重点

- 重点区分：`e` vs `ê`
- 核心词：`tên`, `đến`, `về`, `ghế`, `mệt`

### 积木骨架

- `Tôi tên là [tên].`
- `Tôi đến [địa điểm].`
- `Tôi về [địa điểm].`

### 10句示例

1. `Tôi tên là ...` / 我叫... / My name is ...
2. `Em tên là gì?` / 你叫什么？ / What is your name?
3. `Tôi đến rồi.` / 我到了。 / I arrived.
4. `Tôi đến lớp.` / 我到教室了。 / I come to class.
5. `Tôi về nhà.` / 我回家。 / I go home.
6. `Tôi về trước nhé.` / 我先走了。 / I will leave first.
7. `Ngồi ghế này đi.` / 坐这把椅子吧。 / Sit on this chair.
8. `Hôm nay tôi hơi mệt.` / 今天我有点累。 / I am a bit tired today.
9. `Câu này dễ.` / 这句很简单。 / This sentence is easy.
10. `Bạn kể lại giúp tôi.` / 你再讲一遍帮我。 / Please tell it again.

## Day04（O组 `o, ô, ơ`）

### 发音重点

- 重点区分：`o`（更开）/ `ô`（更闭）/ `ơ`（中后）
- 核心词：`ở`, `mở`, `tốt`, `sớm`, `chợ`

### 积木骨架

- `Tôi ở [địa điểm].`
- `Mở/Đóng [danh từ] giúp tôi.`
- `Tôi đi [địa điểm] [thời gian].`

### 10句示例

1. `Tôi ở Hà Nội.` / 我住在河内。 / I live in Hanoi.
2. `Bạn ở đâu?` / 你住哪儿？ / Where do you live?
3. `Mở cửa giúp tôi.` / 帮我开门。 / Please open the door.
4. `Đóng cửa lại nhé.` / 请把门关上。 / Please close the door.
5. `Món này tốt.` / 这个不错。 / This is good.
6. `Tôi đi chợ sớm.` / 我早点去市场。 / I go to market early.
7. `Hôm nay tôi đi chợ.` / 今天我去市场。 / I go to the market today.
8. `Nhà này hơi nhỏ.` / 这房子有点小。 / This house is a bit small.
9. `Cô ấy nói rõ.` / 她说得清楚。 / She speaks clearly.
10. `Tôi ở đó.` / 我在那儿。 / I am there.

## Day05（易组 `i/y, u, ư`）

### 发音重点

- 重点区分：`u` vs `ư`
- 核心词：`đi`, `uống`, `mua`, `từ`, `giữ`

### 积木骨架

- `Tôi đi [địa điểm].`
- `Tôi muốn mua [danh từ].`
- `Tôi đến từ [quốc gia].`

### 10句示例

1. `Tôi đi làm.` / 我去上班。 / I go to work.
2. `Tôi đi học.` / 我去学习。 / I go study.
3. `Tôi uống nước.` / 我喝水。 / I drink water.
4. `Tôi muốn mua nước.` / 我想买水。 / I want to buy water.
5. `Tôi đến từ Trung Quốc.` / 我来自中国。 / I am from China.
6. `Bạn giữ giúp tôi nhé.` / 你帮我拿一下。 / Please hold this for me.
7. `Chừng này đủ rồi.` / 这些就够了。 / This is enough.
8. `Hôm nay tôi rất vui.` / 今天我很开心。 / I am very happy today.
9. `Từ này khó đọc.` / 这个词难读。 / This word is hard to pronounce.
10. `Bạn đi cùng tôi không?` / 你和我一起去吗？ / Do you want to go with me?

## 每日复盘动作（固定）

- 从 10 句中选 3 句做“个人常用句”。
- 录音 30-45 秒，优先保证可懂度而不是语速。
- 把最不稳的 2 个音点写入 `08_错题与复盘/个人错音清单.md`。
