# 句子积木学习说明

目标：把越南语表达拆成可复用的“积木块”，通过拼装快速开口。

## 核心思路

- 不是背整句，而是掌握句子槽位（slot）。
- 每个槽位只放高频词，先稳定再扩展。
- 同一个句型每天替换 3-5 个词，形成自动化表达。

## 句子积木结构

- `主语`：我/你/他...
- `时间块`：今天/现在/明天/已经/正在/将要
- `动作块`：去/吃/喝/学/买/看/说
- `对象块`：水/饭/书/越南语/这个
- `状态块`：忙/累/开心/不懂/可以
- `礼貌块`：请/谢谢/不好意思

## 每日训练法（15-20分钟）

1. 选 1 个句型模板。
2. 每个槽位换词，做 10 句。
3. 读 + 说 + 录音，保留最顺口的 3 句。
4. 用这 3 句做 30 秒微场景。
