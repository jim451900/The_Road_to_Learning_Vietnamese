# 连接词与扩句模块

目标：把“短句”升级成“自然小段”。

## 高频连接词

- `và` / 和 / and
- `nhưng` / 但是 / but
- `vì` / 因为 / because
- `nên` / 所以 / so
- `rồi` / 然后；已经 / then; already
- `sau đó` / 之后 / after that
- `nếu ... thì ...` / 如果...就... / if ... then ...

## 扩句公式

1. `主句 + và + 主句`
   - `Tôi học tiếng Việt và tôi luyện phát âm.`

2. `主句 + nhưng + 主句`
   - `Tôi muốn nói nhanh nhưng tôi nói chưa rõ.`

3. `vì + 原因, nên + 结果`
   - `Vì hôm nay bận, nên tôi học ít hơn.`

4. `时间 + 主句 + rồi + 主句`
   - `Buổi sáng tôi đi làm, rồi buổi tối tôi học tiếng Việt.`

5. `nếu ... thì ...`
   - `Nếu bạn nói chậm, thì tôi hiểu tốt hơn.`

## 每日扩句练习（10分钟）

- 从当天 10 句里选 3 句
- 用连接词把 3 句变成 2 组双句
- 再做 1 组三句小段

## 结果标准

- 能说出 2 组双句（每组 8-12 秒）
- 能说出 1 段三句（20-30 秒）
